# ARC Furniture Studio

一个以现代家具为主题的动态中文宣传页，包含空间与材质选择、产品详情、价格与促销信息，以及设计需求表单。

## 特色

- 三款核心家具产品与沉浸式摄影视觉
- 原价、促销价与成交量详情
- 场景和材质切换
- 家具卡片 3D 悬停反馈
- 分层开场动画与轻量交互动效
- 响应式桌面端与移动端布局
- 轻量 WebP 图片资源
- GitHub Pages 自动部署

## 本地预览

站点是无构建步骤的静态页面，直接用任意本地静态服务器托管 `dist` 目录即可。

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173/`。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动把 `dist` 目录发布到 GitHub Pages。

## 数据说明

页面中的价格、促销与成交量以项目维护者提供的数据为准。尚未提供的数据会明确标注为待接入，不会自动生成。
